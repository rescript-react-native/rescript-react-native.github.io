Low-level list primitive. Prefer [`FlatList`](/docs/flatlist) /
[`SectionList`](/docs/sectionlist) unless you need custom data accessors.

See the binding in
[`src/components/VirtualizedList.res`](https://github.com/rescript-react-native/rescript-react-native/blob/main/src/components/VirtualizedList.res)
for `getItem` / `getItemCount` / `getItemLayout` and scroll helpers
(`scrollToIndex`, `scrollToOffset`, …).
